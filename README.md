# My opinionated Emacs Config

## Focused on:
1. Evil mode
2. Mini-buffer improvements
3. Better help
4. Key menus
5. Lisps

## Notes:
- I only use Emacs in Linux.  Windows users will probably have problems, so just switch to Linux 😀
- Hacking Emacs with elisp is hard enough, but messing with evil-mode is a whole extra level of pain, so if you're coming from Vim I would suggest starting with Doom Emacs.
- I've spent a lot of time getting Emacs to my liking, was it wasted?  Most of the stuff I learned was Emacs specific and I will promptly forget it in a few months, but owning the best development system ever made for the rest of my life is in my opinion worth it.
